**Locked decisions:** CSP gains `data:` in img-src across ALL seven declaring files + the byte-exact `PortfolioThemeRenderingTest:55` assertion updates in the same commit (§2.2 — Leaflet's aborted-tile placeholder is a data: GIF); tile URL is `https://tile.openstreetmap.org/{z}/{x}/{y}.png` maxZoom 19, NO `{s}` subdomain, NO Referrer-Policy added (§2.5); `L.Icon.Default.imagePath` set explicitly before any marker (§2.4); tile-URL default lives in `roller.properties`, NOT runtimeConfigDefs (MessageKeyTest ratchet is at exactly 48/48 — §8.2); `[map auto=]` copies `GalleryShortcode`'s private-dir null-refusal + try/catch gates verbatim (§4.3 — Wave 2's Important finding was exactly a private-dir metadata leak; GPS coordinates ARE metadata); CTA emits `<a>` only (no button), validates href absolute-http(s) and returns null otherwise (§1.6 — invalid href silently deletes the anchor); FAQ emits `<dl>/<dt>/<dd>` (details/summary not allow-listed); jsonld_type is a Java enum over a nullable VARCHAR(32), BLOG_POSTING default; TouristTrip.itinerary derives from `[map]` pins in source order; Event.location is a name-only Place (no fabricated address); FAQPage ships for correctness with the documented Google-rich-results caveat (§3.4); rendering tests use a 127.0.0.1 context URL (UrlValidator rejects TLD-less localhost); no free-form JSON-LD textarea (rejected, §3.4).
