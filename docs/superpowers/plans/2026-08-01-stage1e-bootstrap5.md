> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the JSP admin UI from Bootstrap 3.4 (EOL) to Bootstrap 5.3, remove the vestigial dual-editor plugin layer (Summernote becomes the one editor), and finish the documentation guides — closing Stage 1.

**Architecture:** Executed from the verified census at `.superpowers/sdd/2026-08-01-stage1e-bootstrap5/bs5-census.md` (§-numbers below cite it). Order: editor refactor first (so EntryEditor's JSP is converted once), then the foundation swap + chrome (head.jsp/webjar, roller.css surgery incl. the §1 chevron hack, banner/menu/messages + tabbedpage layout — 76% of views get correct shell), then content JSPs in two disjoint batches (parallel worktrees), then the sweep + docs, then the final battery. The browser IT suite is the visual-correctness gate: it must be green after EVERY task that touches runtime files (BrowserHealth catches 404ing assets and JS console errors — the exact failure modes of a half-done Bootstrap migration).

**Conversion recipe (normative, from §1):** panel/panel-default→card, panel-heading→card-header, panel-body→card-body, panel-title→card-title (or app-owned class where an IT marker needs stability); form-horizontal groups→`row mb-3` + `col-form-label`; control-label→col-form-label; col-sm-offset-3→offset-sm-3; col-xs-*→col-*; select.form-control→form-select; btn-default→btn-secondary; input-group-addon→input-group-text; label label-*→badge bg-*; badge→badge bg-secondary; sr-only→visually-hidden; form-control-static→form-control-plaintext; img-responsive→img-fluid; data-toggle/dismiss/target→data-bs-*; data-parent→data-bs-parent; class="close"→btn-close; pager→hand-rolled prev/next buttons; well→card card-body; glyphicon-X→Bootstrap Icons `bi bi-Y` per the §1 glyph list (add org.webjars.npm:bootstrap-icons, load its font css in head.jsp); jQuery `.modal()`/`.alert()` calls→`bootstrap.Modal.getOrCreateInstance(...)`/plain remove per §1/§2.
