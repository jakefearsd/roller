# docs/README.md

In this directory you'll find design documentation and various examples.

* `api/` - the `/api/v1` automation API: endpoint reference, curl recipes, and
  the error contract. There is no UI for minting a token, so this is the API's
  front door, not a supplement to one.
* `design/` - the admin UI design system and approved component mockups
* `examples/` - example configuration and script files
* `readme-images/` - screenshots used by earlier revisions of the top-level README
* `superpowers/` - committed specs and implementation plans for past and in-flight work
